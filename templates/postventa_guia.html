Módulo: Órdenes de Trabajo Asesor

¿Quién accede? Asesores de Servicios, Recepcionistas y Supervisores

Funciones del Asesor:

1. Ver Ingresos Pendientes
  • Visualiza los vehículos que te fueron asignados para atención
  • En la pestaña "Ingresos" aparecerán los turnos que se te hayan asignado para atender
2. Atender al Cliente (Primera vez)
  • Presiona el botón "Atender" cuando el cliente llega
  • Realizas la recepción del vehículo y la atención inicial
3. Pactar Hora con el Cliente
  • Una vez revisado el vehículo, presiona "Pactar Hora"
  • Ingresa la fecha y hora comprometida para el retiro
  • Esto genera el compromiso de entrega con el cliente
4. Atender Egreso del Cliente
  • Cuando el cliente retorna, aparecerá en la pestaña "Egresos"
  • Presiona "Atender" cuando lo recibas
5. Entregar Vehículo
  • Una vez listo para entregar, presiona "Entregar"
  • Esto completa el ciclo del servicio
  • El registro pasa a historial

Módulo: Gestión de Servicios Recepcionistas

¿Quién accede? Personal de recepción y Supervisores

Funciones de recepción:

1. Importar la base de datos de turnos desde Excel
  • Arrastra el archivo .xslx al área designada, o haz click en ella para poder explorar tu equipo
  • El sistema validará y cargará los turnos automáticamente
  • Los turnos se crearán en estado "Por Asignar" y estarán disponible para su asignación
2. Asignar a Asesor (AT o MT)
  • En la pestaña "Por asignar" se habilitará la lista de turnos pendientes
  • Selecciona el turno que deseas asignar
  • Presiona AT (asignación automática) o MT (asignación manual)
  • Cuando aplique, el sistema distribuira de manera equitativa los turnos entre los asesores disponibles
  • Inicia el cronómetro de espera del cliente
3. Reasignar Turno
  • Si un cronómetro está activo, puedes reasignar el turno
  • Presiona "Reasignar" y selecciona el nuevo asesor
  • El sistema registra el asesor original para reportes
4. Notificar Retiro del Cliente
  • Cuando el cliente llega a retirar (estado: Hora Pactada)
  • Presiona "Retiro"
  • Esto inicia el cronómetro de espera del egreso
  • El turno pasa a "Esperando Retiro" para que el asesor lo atienda
5. Visualizar Cronómetros
  • Cronómetro Ingreso: Desde asignación hasta primera atención
  • Cronómetro Egreso: Desde retiro hasta atención del egreso
  • Se actualizan automáticamente cada 5 segundos
Reglas Importantes:
  • No puedes reasignar si todos los cronómetros están detenidos
  • El botón "Retiro" solo aparece cuando el estado es "Hora Pactada"
  • Una vez entregado, el turno pasa automáticamente al historial

Módulo: Registros y Reportes Supervisor/Admin

¿Quién accede? Solo Supervisores y Administradores

Funcionalidades del Reporte:

1. Historial Completo
  • Visualiza todos los servicios entregados
  • Filtra por fecha, asesor o sector
  • Incluye 7 timestamps del ciclo completo
2. Detalle del Servicio
  • Línea de Tiempo Completa:
    • 1. Asignado - Cuando gestión presiona AT/MT
    • 2. Atendido (Ingreso) - Primera atención al cliente
    • 3. Hora Pactada con Cliente - Momento del compromiso
    • 4. Hora Comprometida - Hora prometida para retiro
    • 5. Cliente Retira - Notificación de retorno
    • 6. Atendido (Egreso) - Atención del retiro
    • 7. Entregado - Cierre del servicio
3. Métricas Calculadas
  • Tiempo Espera Ingreso: Desde asignación hasta primera atención
  • Tiempo Atención Ingreso: Desde atender hasta pactar hora
  • Tiempo Espera Egreso: Desde retiro hasta atender egreso
  • Tiempo Atención Egreso: Desde atender egreso hasta entregar
  • Tiempo Total Servicio: Suma de los 4 tiempos anteriores
4. Tracking de Reasignaciones
  • Visualiza si un turno fue reasignado
  • Muestra el asesor original y el asesor final
  • Identificado con indicador amarillo
5. Retiros Programados
  • Tabla ordenada por horario pactado
  • Muestra todos los turnos con hora comprometida
  • Estados: Pendiente, Esperando Retiro, Listo, Entregado
Uso Estratégico:
  • Identifica cuellos de botella en los tiempos de espera
  • Evalúa desempeño de asesores por tiempos de atención
  • Detecta frecuencia de reasignaciones para balancear carga
  • Analiza cumplimiento de horarios pactados

Módulos de Administración Supervisor/Admin

Administración de Asesores
  • Dar de alta/baja asesores de AT y MT
  • Editar nombres y sectores
  • Controlar disponibilidad activa/inactiva
Administración de Servicios
  • Crear tipos de servicio personalizados
  • Asignar asesores fijos a servicios específicos
  • Activar/desactivar servicios según necesidad
